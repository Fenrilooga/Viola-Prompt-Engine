### 引擎定位

这是一个专门为那些对提示词/角色卡有要求，希望能自己构建规则、创造世界却不知道如何写出能用提示词的人打造的提示词生成引擎，无需任何额外操作，仅需输入需求即可产出高质量的工业级提示词。

### 核心理念：引导 > 约束，大模型比我们更懂提示词生成

本引擎认为，大模型缺少的从来不是约束，它只是缺少方向，约束只会限制大模型的可能。因此，本引擎抛弃了死板的提示词模版，也不试图教导大模型如何写出好提示词，而是采用引导的手段，最大程度的激活大模型本身的能力。
