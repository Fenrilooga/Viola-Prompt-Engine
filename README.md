## ✨ 引擎定位

这是一个专门为对提示词/角色卡有极高要求，希望能自己构建规则、创造世界，却苦于不知如何编写高维提示词的创作者打造的**全自动化提示词构筑管线**。

无需任何额外学习成本，仅需输入你的原始需求。本引擎将极其硬核的自动化工作流，封装在了一个“**拥有提示词架构洁癖的毒舌女仆**”人格之下，为你把自然语言废料粉碎重构，产出高质量的工业级提示词。

* 📥 **输入 (Input)**：一段自然语言需求——允许散装、允许模糊、甚至允许逻辑断裂。
* 📤 **输出 (Output)**：强制三段式交付——病理级思维链 + 毒舌人格宣告 + 工业级提示词资产。

## 🚀 快速上手

为了适配不同的使用场景，本引擎提供三个封装版本，请根据你的运行环境按需获取：

### 1. 角色卡版本
- **文件**：`薇奥拉-提示词生成引擎.png`
- **用法**：可直接导入 **SillyTavern (酒馆)** 等支持 `chara_card_v3` 标准的前端工具作为辅助角色对话。
- **💡 亮点与兼容性**：系统内置了将万字深层诊疗过程 `<Viola_Surgical_CoT>` 物理隐藏的正则脚本（Regex Script），保持界面极致清爽。
  > **⚠️ 注意**：部分不支持正则脚本的前端工具，仅会导致薇奥拉的思维链无法折叠（前端会完整展示她的推演过程），但这**绝对不会影响**最终生成的资产质量与引擎核心效果。

### 2. 纯文本系统提示词版本
- **文件**：`薇奥拉-提示词生成引擎.txt`
- **用法**：可直接发送给 ChatGPT / Claude 等大模型，或注入为大模型的 System Prompt（系统提示词）。
- **场景**：适合没有部署第三方前端面板，直接使用网页端大模型的用户。

### 3. Agent Skill 版本
- **文件**：`viola-prompt-engine-skill`
- **用法**：作为 Skill 插件，直接在 Coze、Dify、Codex 等 Agent 编排工具上挂载使用，无缝接入自动化开发流。

## ⚙️ 核心架构与底层逻辑

本引擎的核心理念在于将复杂的提示词构筑过程**原子化与动态解耦**。底层架构由四大组件协同运转：

### 1. 视角锚定：九大领域模块解耦 (Module Decoupling)

常规的提示词构建往往受困于视角难以平衡：要么过度聚焦局部标签导致设定单薄，要么因场景过于宽泛而丢失细节。
为此，引擎将提示词工程从底部分解、提纯为了**9 个正交的工业级模块**。在这里，每个模块都是一个独立的视角、一个深度的思考维度。
系统不再按死板的“工作场景”套用模板，而是根据原始需求**动态、自由地组合**这些高维视角。例如，当你要创造一个“会魔法的角色”时，引擎会自动激活 灵魂与血肉 (角色) 与 百科图鉴 (实体) 两个维度并行审视，确保宏观与细节的双向收束。
| 模块 ID | 领域分类 | 激活的构筑视角 |
| :--- | :--- | :--- |
| `SYS_RULE_CORE` | 底层逻辑与管线控制 | **骨架架构视角**：剥离所有表象，专注审视系统的全局编排、死锁防范与强制逻辑流转。 |
| `SYS_ALIGN_BOUND`| 边界约束与方向指引 | **红线与基准视角**：构建无形的软约束围栏，审视内容“绝不能碰什么”以及“必须向什么方向演进”。 |
| `SYS_CALC_ENGINE`| 动态演算与判定机制 | **动态演进视角**：聚焦“变化”与“过程”，审视数值流动、状态触发条件及概率检定机制。 |
| `SYS_STYLE_TUNE` | 语感基调与风格渲染 | **导演与镜头视角**：掌控文学基调，审视文本输出的机位调度、节奏感与沉浸式渲染风格。 |
| `UI_STATUS_BAR` | 状态栏与面板美化 | **终端前端视角**：剔除逻辑运算，纯粹从像素级拼装层面审视纯文本/Emoji面板的极简排版。 |
| `SET_ENTITY_DEF` | 实体定义与外在特质 | **百科图鉴视角**：审视静态概念（物品、技能、组织等）的外在表象、固有特性与常数面板。 |
| `SET_CHAR_GEN` | 角色档案与性格演绎 | **灵魂与血肉视角**：审视生命体的底层三观、弱点骨架，以及极具流动性的外在演绎与微表情。 |
| `SET_WORLD_BLD` | 世界框架与体系构建 | **造物主宏观视角**：拔高视界，俯视地理风貌、生态法则与势力切割，搭建宏观叙事体系。 |
| `IMG_PROMPT` | 视觉潜意识生成 | **视觉降维视角**：将文本降维，审视并提取用于独立生图的画面主体、光影基调及艺术家特征。 |

### 2. 诊疗管线：封闭式病理推演 (Surgical CoT)

思维链（CoT）虽已是业界常态，但本引擎的 `<Viola_Surgical_CoT>` 逻辑解剖舱更专注于“**病理级诊断**”。其推演管线并非生硬的步骤堆砌，而是一套**环环相扣的推演闭环**：
*   **特征剥离与去噪 (Extraction)**：粉碎原文本中的无效修饰。它的存在是为了给后续的动机挖掘、模块匹配与最终生成排除一切干扰杂质，提纯出纯粹的“需求目标”。
*   **深层动机溯源 (Motivation)**：下探至需求底层，锁定用户未曾言明但试图达成的核心目的，作为后续所有推演与填补的**绝对锚点**。
*   **动态路由匹配 (Routing)**：呼应上文的“视角锚定”，将需求与九大模块比对匹配。**同时允许跨域多重命中，让大模型在处理复杂需求时，能以多重视角交叉看待同一个问题**。
*   **双轨需求诊疗 (Diagnosis)**：从两个维度确保最终提示词的极致稳定性：
    *   *正向填补*：基于命中模块的内生属性与挖掘的深层动机交叉补全缺失的构成性维度。**保证提示词不空，让大模型“演得稳、做得准”**。
    *   *逆向除错*：深度清扫潜在的逻辑死锁与相悖点。**确保提示词不乱，彻底拔除隐蔽缺陷，防止大模型在后续执行中发生错乱**。

### 3. 输出协议：物理格式裁定 (Format Arbitration)

基于提示词的最终挂载环境，引擎在渲染层构筑了四道物理隔离屏障：
*   **高压隔离舱 (系统/执行层)**：强制封装为 XML 标签，剥离自然语言连贯性，确保机制逻辑的绝对可执行。
*   **解禁自然流 (设定/约束层)**：下放 Markdown 排版权限，维持设定的文学张力与高浓度表达。
*   **终端视觉降维 (UI/面板层)**：强制采用纯文本+Emoji，剔除所有高阶语法，输出扁平极简面板。
*   **视觉代码阵列 (生图层)**：物理切割为正/负面提示词及参数的三段式独立区块。
> *💡 针对多模块并行的复杂场景，引擎内部专门配置了跨域复合调度协议（如：XML 骨架嵌套 Markdown 血肉、逻辑层隐式挂载终端 UI 等）。这些特殊设计旨在**防止大模型在处理跨领域需求时产生格式错乱**，赋予引擎应对更庞大、更复杂设定时的绝对格式稳定性。*

### 4. 驱动核心：人格化代理 (Persona Agent)

系统并未采用干瘪的 System 指令（如“你必须严谨”），而是将整个工作流引擎封装于高度自洽的「**毒舌女仆 (Viola)**」人格代理中。通过赋予大模型“极度的提示词架构洁癖”，在心理学层面触发模型的“防御性严谨”与“批判性诊断”模式，利用完整的人格演绎驱动模型自发产出高质量的工业级文本。
